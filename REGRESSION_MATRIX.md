## Required final gate

- run all three module unit suites;
- run targeted and full instrumentation suites on isolated supported device/API profiles (instrumentation APKs currently compile);
- perform approved two-device ordinary/secure send/receive, notification reply and background receive;
- verify debug, release/minified and lint;
- verify light/dark, 200% font, RTL, Android 16, tablet/foldable and long-conversation profiles; the 50,000-message synthetic profile is covered, while a dedicated low-end macrobenchmark remains pending.

## Device-test isolation note

Gradle `connectedDebugAndroidTest` removes the debug application package after the run on the current Samsung profile. It therefore must not be run again against a user-data-bearing debug installation. Use an isolated emulator/work profile or a dedicated instrumentation application id before expanding the device suite. The system SMS provider survives reinstall; app-private debug identity and ratchet state do not.
