# Обновления через GitHub

Приложение использует схему **GitHub Releases → подписанный универсальный APK → системный установщик Android**, как проекты 12609 и Palenok.

В разделе **Настройки → Обновления** пользователь может проверить последний стабильный выпуск, скачать APK с прогрессом и отменой, открыть описание выпуска и передать проверенный файл системному установщику. Приложение не устанавливает APK незаметно и не обходит подтверждение Android.

## Проверки на устройстве

Перед установкой проверяются:

- единственный asset с именем `Messages-*.apk` из официального репозитория;
- объявленный GitHub размер и SHA-256 digest, если GitHub его предоставляет;
- полнота загрузки и ограничение размера в 250 МиБ;
- совпадение application ID с установленным приложением;
- точное совпадение `versionCode` с описанием выпуска и его увеличение;
- совпадение сертификата подписи с установленной версией.

Частично скачанные файлы имеют расширение `.part`, удаляются после ошибки или отмены и никогда не предлагаются к установке.

## Автоматический выпуск

Workflow [Android Release APK](../.github/workflows/android-release.yml) запускается после изменений Android-кода в ветках `messages`, `main` или `master`, а также вручную. Он выполняет модульные тесты, собирает один универсальный APK, подписывает и проверяет его, создаёт SHA-256 файл и публикует стабильный GitHub Release.

Для подписи нужны GitHub Actions Secrets:

- `KEYSTORE_BASE64` — хранилище ключей в base64 без переносов;
- `KEYSTORE_PASSWORD` — пароль хранилища;
- `KEY_ALIAS` — псевдоним ключа;
- `KEY_PASSWORD` — пароль ключа.

Ключ нельзя хранить в Git. Его резервная копия должна находиться в защищённом месте вне репозитория. Потеря или замена ключа лишит следующие APK возможности обновлять существующую установку.

`versionName` строится из версии в `version.properties` и номера запуска Actions. Числовой `versionCode` также растёт с каждым выпуском и записывается в его описание, чтобы приложение могло проверить скачанный APK.

При сборке в другом форке переменная GitHub Actions `GITHUB_REPOSITORY` автоматически встраивает адрес этого форка. Для локальных сборок используется `IgorNadein/Messages`.
